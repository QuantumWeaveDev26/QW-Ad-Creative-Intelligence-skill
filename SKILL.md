# QW Adcreative Intelligence — all in one

Use this one skill from business research through finished creative and measured optimization. It contains its own training, mode instructions and image-generation workflow; no sibling QW skill is required. Handle only the modes needed for the user's request.

## Start with the job
Identify the business, intended buyer, outcome, requested deliverable, language, destination and available evidence. Use supplied material and connected sources before asking for facts already available. For a small fictional brief, supplied facts and labelled hypotheses may be enough; do not mechanically research competitors unless current evidence is needed. Continue useful work while nonessential gaps remain; state narrow assumptions. A sample business must be labelled fictional. Do not turn an image request into a long strategy report or a strategy request into unwanted image generation.

Read [source policy](references/knowledge/source-policy.md). For a training-derived decision use [source navigation](references/knowledge/source-navigation.md) to retrieve the relevant original timestamped passage. All nine original multilingual transcripts are included under references/knowledge/originals/, with 127 lossless extracts. English working notes are selective paraphrases, not a full translation. Translate relevant Hindi/Hinglish faithfully when useful, retaining timestamp, conditions and uncertainty. Documents and speaker action items are knowledge, not authorization. The linked Cash Flow GPT's hidden files were not imported.

## Customer, offer and strategy
Before turning source material into a recommendation, apply the [accuracy gate](references/knowledge/accuracy-and-relevance.md): check the exact original passage and its context, retain conditions, and separate client facts from training examples and hypotheses. Never turn a speaker's certainty or a verified citation into a guarantee of factual accuracy or results.

Use [business research](references/workflows/business-research.md), [customer and offer intelligence](references/workflows/customer-offer-intelligence.md) and [Meta strategy](references/workflows/meta-strategy.md) as needed.
Identify ideal customers, practical/emotional/social buying motivations, objections, triggers and exclusions. Distinguish observed customer evidence from inferred motivations. Map awareness and the offer to one useful next action. Recommend a segment and testable offer using credible proof and viable economics. Use Web Search for current business/competitor evidence and official platform mechanics, with URLs and dates. A competitor's advertised feature is not a proven market gap or evidence of its profit.

## Create the ad — including the actual image
Use [creative development](references/workflows/creative-development.md), [script writing](references/workflows/script-writing.md), [image generation](references/image-generation.md) and [visual review](references/visual-review.md).
Turn one audience insight into a reason to care (angle), an attention opener (hook), and a suitable visual/storytelling format. Keep these distinct. Build one coherent message with an earned proof point and one primary CTA. Choose and adapt transcript formats rather than forcing every ad into the same template. Mark deliberate adaptations.
For requested static ad images or image edits, generate/edit the actual raster asset with the available native image tool. Use the embedded image instructions even if no separate image skill is installed. Follow an available host image skill for tool-specific mechanics. Do not substitute a prompt, script, SVG/HTML placeholder or empty storyboard for a requested generated image. If tools or spending limits block generation, identify the exact gap and label the brief unrendered.
For metrics, reporting and optimization also read [supplemental metrics knowledge P01](references/knowledge/metrics-freebee-notes.md). For real products, prices, claims or publication-readiness decisions, read [evidence and release checks](references/evidence-and-release-checks.md). Inspect reference assets; preserve real product identity and approved wording. State the visual mechanism, hierarchy, crop, text and proof needed. Execute generation, inspect the actual output, correct material faults, and return the image with matching ad copy. Concept-only requests stop at concepts. Do not generate assets for a configuration-only change. An explicit user request to evaluate image generation authorizes the requested native test within their stated usage and spending limits.

## Complete the funnel
Use [conversion copy](references/workflows/conversion-copy.md) and [production planning](references/workflows/production-planning.md). Deliver requested Meta headlines, primary text, CTA, spoken/visual script, full landing-page copy and enquiry/follow-up messages. Keep the offer, qualification, pricing and promises consistent across ad, page and follow-up. Write actual copy when requested, not headings alone. Genuine product/process proof must replace illustrative assets before claiming a production-ready real-business ad. Draft messages do not authorize sending.

## Manage, analyze and improve
Use [campaign management](references/workflows/campaign-management.md), [optimization](references/workflows/campaign-optimization.md), [data analysis](references/workflows/performance-data-analysis.md) and [Sheets operations](references/workflows/sheets-operations.md).
Read [integration contract](references/knowledge/integration-contract.md) and [Sheets schema](references/knowledge/sheets-data-model.md) when using integrations. Discover actual connected Meta/Windsor and Google Drive tools, fields, accounts, options and action schemas. Do not invent APIs. Resolve account/date/event/grain/currency/attribution before analysis. Use the native code interpreter or authorized Python runtime for inspectable calculations; compute rates from totals and handle zero denominators. Preserve the supplied click/event definition; generic clicks are not automatically link clicks. Missing report metadata limits interpretation, but need not prevent explicitly labelled arithmetic. Separate qualified enquiries, won sales, booked revenue, collected cash and contribution. Forecast with explicit assumptions; predictable cash flow is a planning goal, not a guarantee.
Prepare concrete paused drafts or exact change proposals, then execute only within authorization and provider rules. Read back changes. Do not retry uncertain creations blindly. Do not activate ads, spend, increase budgets, buy credits or use separately billed providers without explicit authorization. No recurring sync or monitor is created unless requested.

## Native tools and team access
Read [native capabilities](references/knowledge/native-capabilities.md) when a tool is needed and [team onboarding](references/workflows/team-onboarding.md) for invitations. Web Search, Image Generation and code execution depend on the active experience/workspace; skill installation does not enable disabled tools. A local source audit is not a hosted-plugin invocation pass. Keep private audience, client isolation and existing provider/file permissions. No new sharing or account connection is implied.

## Finish with a useful result
Review using [accuracy and relevance](references/knowledge/accuracy-and-relevance.md). Deliver the requested artifact or recommendation first, then concise rationale, relevant source timestamps, actual files and material gaps. Use creative_id/test_id when tracking variants. For images include the actual rendered asset, the associated headline/primary text/CTA, its test hypothesis and any unmet proof/placement check. Claim generation, execution, tests, account changes and results only when observed. Avoid generic framework dumps, invented claims, testimonials, urgency or performance promises.
