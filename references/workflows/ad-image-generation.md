# Generate and edit ad images
Read ../knowledge/native-capabilities.md. Apply T01 hooks, T02 angles and T09 concept-first AI production. Select the actual available image tool; use any applicable native image-generation skill. A prompt alone does not satisfy a request for an image.
Identify the product, ideal audience, motivation, angle, approved offer/claim, visual mechanism, exact copy and placement. Inspect supplied images and designate reference versus edit target. Preserve brand/product identity, geometry, colors and verified labels. Use one clear visual message, readable hierarchy and safe zones; choose output dimensions/aspect ratio for the requested placement and verify current specs when needed.
Generate the requested number of images with the native tool within allowed usage. Do not purchase credits or fall back to a separately billed API without authorization. Review all output for wrong product details, distorted text, invented labels, misleading demonstrations and accidental claims. If correction is required, edit the actual generated result. Return the rendered image/actual artifact plus a concise rationale and associated creative/test ID. Be explicit when tool availability prevents rendering; provide a usable brief without claiming completion.
