# Complete conversion copy system
Use T01/T02/T03/T07/T08 for the creative principles. Landing-page, qualification and follow-up procedures are operational extensions. Start from an ideal customer, motivation, awareness, verified offer, proof register, destination and one intended action. If these are absent, derive a draft from available evidence and mark the precise assumptions. Do not reuse a generic promise across unrelated segments.

## Meta ad package
For each requested concept deliver creative_id, audience, buying motivation, angle, format/visual brief, hook, spoken script if needed, primary text, headline, optional supported description, CTA and destination. Offer concise variations that test one useful difference. Verify current placement limits if providing ready-to-upload fields; count characters when a limit matters. Link specific objections to actual evidence and keep ad and destination promises consistent.

## Landing-page copy
Write the actual copy when asked, not just a wireframe. Include audience-specific hero headline/subheading, value proposition, one primary CTA, problem/context, solution and mechanism, relevant benefits, verified proof, offer/inclusions, process, objection FAQs, eligibility/qualification, truthful risk reduction and closing CTA. Explain what happens after submission and expected response time only if known. Request only useful lead fields. Put key qualification (location, minimum order, use case, realistic price indication where relevant) where it helps filter fit. Claims, pricing and guarantees must match the ad. No fake testimonial, logo or invented case study. Flag missing legal/policy text rather than fabricating business commitments.

## Enquiry and follow-up messaging
Draft the requested WhatsApp/DM/form confirmation/email/quote follow-up sequences. Each message has trigger, purpose, exact text, next action and stop condition. Establish consent/contact context, qualification, timing, expectations and handoff. Ask only the next useful question. Separate lead acknowledgement, discovery, offer/quote, objection handling and reminder. These are drafts; send nothing without explicit instruction. A WhatsApp draft does not install automation or authorize bulk outreach.

## Copy audit
Assess audience specificity, hook, single message, motivation, offer clarity, proof, objection coverage, language, CTA, qualification and ad-to-page continuity. Show a focused rewrite and why it improves the hypothesis. Avoid unsupported performance promises. Deliver evidence references and the next experiment, not a claimed conversion uplift.

For a complete funnel or changed CTA, apply [funnel review](../funnel-review.md). Check actual copy across stages, including alternate destinations, the distinction between enquiry and confirmed service, conditional acknowledgements and downstream metric definitions. Do not treat a page's existence as evidence that it fulfills every variant's promise.



## Useful copy with incomplete operations
Requested page sections are guidance, not permission to invent a process, response time, refund, proof point or guarantee. Write a shorter fact-bounded page when that is all the evidence supports, with specific publication dependencies separately. A copy CTA is not a verified platform enum or a functioning form.
