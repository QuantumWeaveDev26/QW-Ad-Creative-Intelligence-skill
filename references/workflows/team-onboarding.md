# Team onboarding
Read integration-contract.md. Intended for named team members and explicitly invited people. Do not publish, grant public/whole-workspace access or invite anyone without instructions. Invitations expose packaged training. Resolve exact recipient IDs before authorized sharing and preserve existing audience. A private link is not an access grant. External guests depend on actual workspace support.
Check plugin access, own/shared Windsor connection, correct Meta assets/permissions, Sheets destination/Drive access and authorized spending scope. Keep credentials in provider OAuth/secret systems. Operating roles are not custom RBAC enforcement.
Acceptance: resolve requested client, read a bounded authorized report, produce a source-cited concept, preview a designated test-tab update and verify a paused object only if specifically authorized. No spend is necessary. Record pass/fail/pending with evidence. No invitation is sent without explicit recipients and authorization. On revocation check plugin/provider/file access separately.
