# Script writing
Use T01/T02/T07/T08 plus the relevant format module. Write one conversational idea, start with a relevant specific hook, build trust and resolve the promise. Starting framework HPSCPC: hook, problem, solution, credibility, pitch, CTA. Alternatives: transformation, myth bust, demo, proof stack, curiosity reveal. Choose rather than forcing one formula onto every format.
Output a timed table: estimated seconds, visual/action, spoken line, on-screen text, proof/asset and edit/audio note. Add primary text, headline, supported description, CTA label, destination and language. Estimate duration by reading aloud; course durations are not platform mandates.
Check specificity, hook/body/CTA flow, one message, spoken rhythm, evidence and realistic product behavior. For rewrites explain weaknesses and edits. Keep verified promises; never insert example refunds or stock limits as facts. Translation deliverables retain original excerpt, timestamp, natural rendering and uncertainty. Working notes are not full translations.
