# Code Interpreter & Data Analysis for performance and cash flow
Read ../knowledge/native-capabilities.md and sheets-data-model.md. This skill uses the available runtime; it does not enable a disabled interpreter. Use the native interpreter when exposed; in Codex an authorized Python runtime is an alternative. State the actual surface if relevant.

Load only authorized data and inspect the schema, reporting period/grain, identifiers, duplicates, missing values, currency, timezone, event and attribution before calculation. Preserve raw inputs. Resolve conflicting totals or report the exact limitation. Compute spend and outcome totals, weighted rates, qualified-lead cost, funnel conversion and contribution with explicit denominators. Use real calculations, not guessed arithmetic. Join CRM/orders on verified keys and assess join loss/multiplication. Distinguish Meta-attributed conversions, CRM sales and cash collections.

For forecasting, define qualified enquiry and use measured qualification rate, close rate, average contract/order value, payment timing, refunds, variable costs and budget/capacity. If only assumptions exist, produce labelled low/base/high scenarios. Define whether close rate starts from all leads or qualified leads; do not apply qualification twice. Attribute collections to actual dates or a documented lag. Cash after ads alone is not profit or complete net cash flow. State omitted costs and beginning-cash assumptions. Never guarantee predictable cash flow.

Deliver executed calculations, requested tables/charts/files, data sources, assumptions, reconciled totals, material uncertainty and recommended next test. For statistical comparisons disclose sample limitations and observational allocation. Follow spreadsheet skills for workbook deliverables. Never claim an analysis was run, a chart rendered or a file created without tool evidence. Report runtime limitations precisely and retain a reproducible method if execution is unavailable.



## Metric definition before interpretation
Generic clicks remain generic clicks. Compute and label generic CTR/CPC if those are the supplied counts; do not call them link CTR/CPC without evidence. Missing windows/attribution need not block transparent synthetic arithmetic, but do block a real-account winner or budget conclusion. Keep missing metadata, comparability assumptions, sample limits and the next evidence check visible.


For source-based metric interpretation read [P01 metrics notes](../knowledge/metrics-freebee-notes.md), especially click definitions, denominator choices, attribution, estimated reach and the contextual frequency warning. Do not turn these notes into automatic pause/scale rules.
